# CLI-Anything

Build a complete, stateful CLI harness for any GUI application.

## Overview
When asked to build or generate a CLI interface or harness for a software package or GUI tool:
1. Review the software codebase and map internal APIs and operations to CLI commands.
2. Structure the CLI using Click/Python with rich interactive and machine-readable JSON output (--json).
3. Follow the test-driven harness development loop: Phase 0 (Source Acquisition), Phase 1 (Analysis), Phase 2 (Architecture), Phase 3 (Implementation), Phase 4 (Verification).
